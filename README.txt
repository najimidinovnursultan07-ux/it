TRAVEL KG — HTML/CSS/JavaScript демо туристтик сайт

ИШТЕТҮҮ:
1. ZIP архивди чыгарыңыз.
2. TRAVEL-KG папкасын VS Code менен ачыңыз.
3. index.html файлын браузерде ачыңыз. Жакшысы VS Code'догу Live Server extension колдонуу.
4. Турлар барагы: tours.html
5. Админ панель: admin.html

ФУНКЦИЯЛАР:
- Турларды издөө, өлкө/баа/текст боюнча фильтрлөө жана сорттоо
- Избранное (LocalStorage)
- Брондоо өтүнмөсүн сактоо (LocalStorage)
- Катталуу жана кирүү демо системасы
- Админ панелден тур кошуу/өчүрүү
- Responsive дизайн

ЭСКЕРТҮҮ:
Бул Frontend демо. Реалдуу төлөм, билет/мейманкана API, коопсуз авторизация жана чыныгы брондоо үчүн Backend жана тышкы сервистер талап кылынат.
Админ баракчасында азырынча авторизация жок — бул окуу/демо долбоор.
Сүрөттөр интернеттен жүктөлөт; Google Fonts да интернетти талап кылат.
